# Security policy

Do not publish exploitable vulnerabilities or real personal data in public issues. Use GitHub's private vulnerability reporting flow when enabled; otherwise contact the maintainer privately via https://github.com/jayDevCodes.

Treat GPS coordinates, phone numbers, authentication material and dairy records as sensitive. Driver GPS collection must be limited to an explicitly active trip. Enforce dairy and role authorization on the server. Rotate any credential accidentally exposed; removing it in a later commit does not make it safe.

Only the latest development version on the default branch is currently supported.
